# ✦ Aesthio

### Discover your aesthetic. Build your look. Make it yours.

**Aesthio** is an AI-powered visual discovery and styling platform designed to help users discover aesthetics, find visual inspiration, and create personalized looks using AI.

Instead of endlessly scrolling through unrelated inspiration, Aesthio brings **AI, fashion, aesthetics, personalization, and discovery** into one experience.

> **Discover → Create → Personalize → Find Similar**

---

## ✨ What is Aesthio?

Aesthio helps users turn an idea, mood, or aesthetic into a visual direction.

Whether you're looking for:

* 🖤 Black & silver streetwear
* 💿 Y2K summer outfits
* 🤍 Old-money essentials
* 💅 Clean-girl nail designs
* 👟 Minimal sneakers
* 💎 Jewelry & accessories
* 🧥 Men's oversized streetwear
* 🎀 Baddie aesthetics
* 🏠 Room & lifestyle inspiration

Aesthio makes it easier to **discover the aesthetic and build a look around it.**

---

## 🎯 The Problem

Finding fashion and aesthetic inspiration online is easy.

Finding **relevant inspiration that actually matches your personal style** is not.

Users often have to jump between different platforms to:

* Find inspiration
* Search for specific aesthetics
* Build outfits
* Compare styles
* Find similar items
* Save ideas for later

Aesthio aims to bring this experience together through an **AI-first visual discovery platform**.

---

## 💡 The Solution

Aesthio combines visual discovery with AI-powered creation.

Users can explore curated aesthetic inspiration through the **Discover** feed, then use **AI Studio** to describe the look they want and generate a personalized direction.

### Example

> "Streetwear baddie, black + silver, oversized, under ₹5000"

Aesthio can turn that idea into a visual styling direction that users can continue exploring and refining.

## ✨ AI Studio

AI Studio is the core creation experience of Aesthio.

Users can describe what they are looking for using natural language.

### Example prompts

```text
Streetwear baddie in black and silver
```

```text
Old money summer outfit
```

```text
Minimal men's wardrobe
```

```text
Y2K accessories under ₹3000
```

The goal is to transform a simple description into a personalized aesthetic or styling direction.

---

## 🧩 Collections

Save and organize inspiration that you want to revisit.

Collections allow users to build their own visual references around different aesthetics, outfits, or ideas.

Examples:

* My Streetwear
* Summer 2026
* Jewelry Inspo
* Dream Wardrobe
* Room Ideas

---

## 👤 Profile

A personalized space for users to manage their Aesthio activity and saved inspiration.

The profile experience connects the user's discoveries, collections, and personal aesthetic journey.

---

## 🔎 Find Similar

See something you like?

Instead of starting a new search, **Find Similar** lets users continue exploring visually related inspiration.

This creates a discovery loop:

**Discover → Find Similar → Discover More → Create with AI**

# 🎨 Design Philosophy

Aesthio is designed around the intersection of:

**AI × Fashion × Aesthetics × Discovery × Personalization**

The visual direction combines the feel of a premium fashion platform with the clarity of a modern AI product.

### Visual language

* Warm off-white backgrounds
* Soft cream tones
* Subtle peach
* Lavender accents
* Light pink details
* Charcoal typography
* Clean modern sans-serif typography
* Large visual content
* Minimal interface elements

The goal is to feel:

> **Premium + youthful + expressive + technology-focused**

Aesthio is inspired by visual discovery platforms, but is intentionally designed with its own identity rather than replicating Pinterest or traditional editorial websites.

# ⚡ Getting Started

## 1. Clone the repository

```bash
git clone https://github.com/Marzia-22/aesthiO.git
```

## 2. Navigate to the project

```bash
cd aesthiO
```

## 3. Install dependencies

Using pnpm:

```bash
pnpm install
```

Or using npm:

```bash
npm install
```

## 4. Start the development server

```bash
pnpm dev
```

Or:

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.
